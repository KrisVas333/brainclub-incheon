# BrAIn Club · Incheon 2026

Mobile-first English/Korean partnership page for FIRST Global Challenge conversations. The page is plain HTML, CSS and JavaScript, with no external assets, analytics or tracking.

## Preview

Open `index.html` in a browser or run a simple local server from this folder:

```sh
python3 -m http.server 8000
```

## Publish with GitHub Pages

The repository is configured to publish the `main` branch from its root. After editing, push changes to `main`; GitHub Pages rebuilds the page automatically.
